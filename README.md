# CIE 9702 Physics 学习系统 — 说明

刷题计划 + 错题本合成一个站点，账号密码登录，学生每一次打勾 / 标错题老师端都能实时看到。

- **学生端：https://equistaric.github.io/plan/**
- **教师端：https://equistaric.github.io/plan/teacher.html**

这个文件夹（`CIE/学习系统/`）就是整个网站：页面 + 题库（`data.json`、`expl.json`、`img/`、`ans/`）。
改动后双击 `deploy.sh`（或终端 `./deploy.sh "说明"`）即可上线，1–3 分钟生效，网址永远不变。

## 账号与计划类型（已停用）

每个学生有一个 **计划类型**（教师端「学生管理」里随时可改）：

| 类型 | 含义 |
|---|---|
| **全套 full** | 四册全做：日常作业 / 阶段复习 / 总复习 / 补充拓展 都是三个勾。阶段复习 → 总复习 → 补充拓展 按时间线排期；**日常作业不计时**（没有截止日、不算落后）。lichun、qinliyun |
| **标准 standard** | 阶段复习 → 总复习 按时间线；补充拓展选做（有勾，不排期）；日常作业视为已交（灰）。yeshurui、maosilin、yanwenhan、liyongxuan |
| **自由 free** | 不排时间线，四册都可以打勾，只记录进度。新加的学生默认这一档 |

排期规则：9 月 4 日开始，截止 = 考试前 3 天（P2 **10/11**、P1 **11/7**），周末量 = 平日量 × 2，
按题数估时（P1 每题 3–4 min，P2 每题 16–20 min，加 25% 对答案与错题时间）。
估算负荷（9 月两卷并行）：标准 ≈ 平日 2 h / 周末 4 h；全套 ≈ 平日 2.9 h / 周末 5.7 h。
想改节奏，改 `专题练习/真题原文件/Topical/_state/build_plan_site.py` 顶部的 `START / EXAMS / BUFFER / RATE / TYPES`，再跑 `deploy.sh`。

## 学生怎么用

学生端四个页签（2026-09-07 重构）：**今天 · 刷题 · 复习 · 我的**。

1. **今天**：等级 / 连续打卡一行；「今天要做」直接列出到期的套题（开始 / 继续 / 去清零）；「继续上次」；待复习三格（选择题错题 / 结构题待强化 / 笔记）。
2. **刷题**：顶部切 Paper 1 / 2 / 4；每章一张卡，四个套题格子带截止日、状态色（绿 = 完成，黄 = 进行中，红框 = 已过期）。点格子进入这套题：
   - **选择题（Paper 1）**：整套题图 + A/B/C/D，边做边存；「提交判分」后立刻出分、逐题 ✓/✗、逐选项解析，答错的自动进错题本（没作答的只算失分）。
   - **结构题（Paper 2 / 4）**：「写题」进入手写页——**默认只有 Apple Pencil / 鼠标能写，手指用来滚动**（没有笔的同学点「☝️ 手指书写」）；
     笔压粗细、四色、三档、整笔橡皮、撤销。流程：写完 →「保存 · 看答案」（评分方案自动展开，笔自动换红色以便订正；自评得分选做）→「下一题」……
     最后一题出现「提交整套」→ 整套进入**批注模式**（不跳页，老师讲评时在原卷上写）→ 底部「错题清零（整合进错题库）」结束。
     手写页顶部有进度条（每格一题，绿 = 已保存，点格子可跳题）；批注模式下每段题图后面有一块**手写笔记区**（横线纸，写满自动加高，「＋ 加高」可手动加），
     笔记区的笔迹随批注一起入库，在「复习 → 批注本」里原样显示。选择题交卷后每题也可「📝 加笔记区」。
     自评没拿满分的题会进「复习 → 结构题强化」（满分来自题目的 [Total: N]）。
   - **讲评批注**（交卷后、老师讲题时）：选择题**直接在套题页的题图上手写**（交卷后每道题自动变成可写的画布，顶部有一条批注工具栏，默认红笔）；
     结构题在手写页里继续写（提交后自动进入批注模式）。讲完点底部常驻的「错题清零（整合进错题库）」→ 第三档点亮、主界面整套标绿，批注汇总到「复习 → 批注本」。
   - 每套题下面保留三个勾（做题 → 对答案 → 错题清零），纸上做的也能手动记录；在线提交后前两个自动打上。
   - 防误触：出现过 Apple Pencil 后，手掌 / 笔附近的手指触碰一律忽略，单指拖动才滚动；不再依赖浏览器的手势判断。
3. **复习**：
   - **选择题错题**：缩略图、复习模式（先想后翻、已掌握退出队列）、PDF 导出（笔记一起印）。
   - **结构题强化**：结构题不判分、也不进错题本——按自评失分比例排序，「重做」时隐藏上次笔迹（可切换查看），写完再自评，满分即攻克（+XP）。
   - **批注本**：所有手写过批注的题，按套题分组，整张题图 + 笔迹渲染出来直接翻看（绿 = 已整合清零）；点题可继续批注。
   - **笔记**：打字笔记（可选）按章节汇总。
   - **题库**：手动标记纸上做错的选择题，或直接跳到某套题在线做。
4. **我的**：等级 / XP、统计、本周活动、18 个成就、本班 XP 榜、账号（改密码、退出）。
5. 所有记录存在账号里，换设备登录就有；没网时先记在本机，联网后自动补传（右上角显示同步状态）。旧版留在本机的记录第一次登录时自动并入。

测试账号：`test / test1234`（测试同学，标准计划，班级 Test）——老师自己试用；教师端班级筛选里它单独一班，不影响真实学生统计。

XP 规则：作答 1 题 +1，选择题答对再 +1，手写提交 1 题 +5，在线提交一套 +20，一套三个勾全打 +10，写 1 条笔记 +2，掌握 1 道错题 +3。
等级 = √(XP/40)+1。成就在主页可见，都是按记录自动判定的。

## 老师怎么看

- **刷题进度**：每个学生的 P1/P2 完成率、落后几套、**在线做题**（提交套数、均分、作答题数、等级）、错题数、最近动静；
  点姓名展开每卷热力图 + 该生错题 + 薄弱考纲点。「全班进度矩阵」一屏看到所有学生每一套题做到第几步（红框 = 该生已过期未完成）。
- **做题结果**（新增）：选一张卷、一套题——
  选择题：每题的错误率、选项分布、**答错的同学（含所选选项）**，讲题时按题号对照；下面还有「学生 × 题目」矩阵和每人得分。
  结构题：「谁写了」矩阵（✓ 已提交 · ✎ 写了未提交 · 📝 有笔记），点格子看该生的手写原迹和笔记。
- **错题分析**：全班薄弱考纲点排行（人次、涉及学生、考纲要求原文）、多人错的同一道题、按学生列表；点题号看题目和答案解析。可按试卷 / 学生筛选。
- **学生管理**：添加学生、改姓名 / 班级 / 计划类型、重置密码、**清空记录**（保留账号）、删除；还能把旧错题本的「同步码」导入给某个学生。
- 页面每 15 秒自动刷新，右上角显示「实时同步中」。

数据库脚本按顺序：`_private/setup.sql`（建表）→ `update1.sql`（班级、Cui 老师）→ `update2.sql`（在线做题、手写、笔记、XP）。都可重复运行。

## 文件与构建

| 文件 | 来源 |
|---|---|
| `index.html`、`teacher.html` | `_state/build_plan_site.py` 用模板 `_state/learn_student.html`、`_state/learn_teacher.html` 生成（题库数据内嵌） |

旧的 `equistaric/physics`（错题本单独站）不再更新，旧版文件在 `CIE/_旧版归档/`。
