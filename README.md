# CIE 9702 Physics 学习系统 — 说明

刷题计划 + 错题本合成一个站点，账号密码登录，学生每一次打勾 / 标错题老师端都能实时看到。

- **学生端：https://equistaric.github.io/plan/**
- **教师端：https://equistaric.github.io/plan/teacher.html**

这个文件夹（`CIE/学习系统/`）就是整个网站：页面 + 题库（`data.json`、`expl.json`、`img/`、`ans/`）。
改动后双击 `deploy.sh`（或终端 `./deploy.sh "说明"`）即可上线，1–3 分钟生效，网址永远不变。

## 账号与计划类型（已停用）

每个学生有一个 **计划类型**（教师端「学生管理」里随时可改）：

| 类型 | 含义 |
|---|---|
| **全套 full** | 四册全做：日常作业 / 阶段复习 / 总复习 / 补充拓展 都是三个勾。阶段复习 → 总复习 → 补充拓展 按时间线排期；**日常作业不计时**（没有截止日、不算落后）。lichun、qinliyun |
| **标准 standard** | 阶段复习 → 总复习 按时间线；补充拓展选做（有勾，不排期）；日常作业视为已交（灰）。yeshurui、maosilin、yanwenhan、liyongxuan |
| **自由 free** | 不排时间线，四册都可以打勾，只记录进度。新加的学生默认这一档 |

排期规则：9 月 4 日开始，截止 = 考试前 3 天（P2 **10/11**、P1 **11/7**），周末量 = 平日量 × 2，
按题数估时（P1 每题 3–4 min，P2 每题 16–20 min，加 25% 对答案与错题时间）。
估算负荷（9 月两卷并行）：标准 ≈ 平日 2 h / 周末 4 h；全套 ≈ 平日 2.9 h / 周末 5.7 h。
想改节奏，改 `专题练习/真题原文件/Topical/_state/build_plan_site.py` 顶部的 `START / EXAMS / BUFFER / RATE / TYPES`，再跑 `deploy.sh`。

## 学生怎么用

学生端四个页签（2026-09-07 重构）：**今天 · 刷题 · 复习 · 我的**。

1. **今天**：等级 / 连续打卡一行；「今天要做」直接列出到期的套题（开始 / 继续 / 去清零）；「继续上次」；复习三格（选择题错题 / 选择题批注 / AS大题批注）。
2. **刷题**：顶部切 Paper 1 / 2 / 4；每章一张卡，四个套题格子带截止日、状态色（绿 = 完成，黄 = 进行中，红框 = 已过期）。点格子进入这套题：
   - **选择题（Paper 1）**：整套题图 + A/B/C/D，边做边存；「提交判分」后立刻出分、逐题 ✓/✗、逐选项解析，答错的自动进错题本（没作答的只算失分）。
   - **结构题（Paper 2 / 4）**：「写题」进入手写页——**默认只有 Apple Pencil / 鼠标能写，手指用来滚动**（没有笔的同学点「☝️ 手指书写」）；
     笔压粗细、四色、三档、整笔橡皮、撤销。流程：写完 →「保存 · 看答案」（评分方案自动展开，笔自动换红色以便订正；自评得分选做）→「下一题」……
     自评有三种状态，套题页和老师端写法一致：**已提交 · 未自评**（蓝，没点「记录」）/ **✓ 自评满分 5/5**（绿）/ **自评 3/5 · 待强化**（红）。
     自评框里的分数只是预填，要点「记录 5/5」或「全对 ✓」才算记录。
     **保存看过答案之后，原答案就锁定了**：之后写的笔迹都算「批注层」（红笔订正、讲评批注），橡皮 / 撤销 / 清空只作用于批注层，
     原答案原样交给老师批改；想重写点「重做」。老师批过的题，题目上会叠加老师的红笔，顶部显示「👩‍🏫 老师批改 4 / 5」和评语，
     套题页每题标「老师 4/5」，「今天」页有「📬 老师批改」卡片。
     最后一题出现「提交整套」→ 整套进入**批注模式**（不跳页，老师讲评时在原卷上写）→ 底部「错题清零（整合进错题库）」结束。
     手写页顶部有进度条（每格一题，绿 = 已保存，点格子可跳题）；**保存看过答案之后**（以及批注模式下）每段题图后面有一个「📝 加笔记区」按钮，点了才出现一块**手写笔记区**
     （横线纸，写满自动加高，「＋ 加高」可手动加）。**在笔记区写过字的题 = 学生自己标的复习重点**，自动进「复习 → AS大题批注」（擦光了会自动移出）。
     手写页支持**双指放大**（100%–300%，不能缩到比 100% 小）：以两指中点为锚，放大到哪停到哪，松手不会回弹或居中；一指拖动平移（带惯性）；
     电脑上滚轮平移、⌘/Ctrl+滚轮缩放；底部「－ 100% ＋」也能调，点百分比回到 100%。
     **笔迹引擎（2026-09-11 重写，学生端 / 教师端共用 `_state/ink_core.js`）**：
     - 写的时候画在一层「湿墨」上，抬笔后用同一个函数、同一组点落到纸上 —— 抬笔前后一个像素都不变（不会再变粗、变形）。
     - 压力：轻写细（约所选笔宽的 35%），正常写约 70%，用力到 100%；**最粗永远不超过所选的那一档**（1.8 / 2.8 / 4.5 px，默认 2.8）。
       Safari 报的压力 = 力 / 4.17，正常写字只有 0.2–0.3，参数按这个标定；起笔几个采样的压力不可靠，用平均值起笔；压力按移动距离平滑，笔停住不会晕开。
     - 位置按时间常数 5ms 稳定（60/120/240Hz 手感一致），笔尖始终画到真实位置，不拖尾；急转弯处分段各自圆头，v/w 的尖角不起刺。
     - **15 种颜色**：常用 3（墨黑 / 深蓝 / 批改红）+ 多巴胺 6（桃粉 / 活力橙 / 芒果黄 / 薄荷绿 / 天空蓝 / 电光紫）+ 莫兰迪 6（雾霾蓝 / 豆沙粉 / 灰绿 / 奶茶 / 烟紫 / 岩灰）。
       工具栏放最近用的 4 个，🎨 打开全部；颜色和笔宽按设备记住。
     - 以前写的笔迹（旧格式）仍用原算法画，外观和以前完全一样。
     **滑动 / 缩放（同日修）**：每个触点落下时判一次、整段不变 —— 笔正在写或刚抬起 300ms 内落下的 = 手掌；接触面 ≥120px（手指平按也到不了）且最近用过笔 = 手掌；
     笔悬停不算用过笔。以前「写完 1.2 秒内手指全部无效」「接触面 ≥70px 算手掌」这两条会误伤指甲长、平按屏幕的同学，已去掉。
     丢了 pointerup 的旧触点会被新手势自动清掉；捏合后剩一指接着拖；撑在屏幕上不动的手指不算第二指；两指平移有 16px 死区不会误缩放；惯性按 iOS 手感。
     套题页 / 复习页在题图上用手指拖也有惯性。页面地址加 `?debug=1` 可在左下角看到每个触点的类型、接触面和判定，方便在学生 iPad 上排查。
     **图形识别**：画完一笔停住不抬笔约 1.5 秒，自动变成直线（接近水平/竖直会吸附）、圆/椭圆、三角形或矩形；变成直线后不抬笔还能继续拖动终点。
     自评没拿满分的题会进「复习 → 结构题强化」（满分来自题目的 [Total: N]）。
   - **讲评批注**（交卷后、老师讲题时）：选择题**直接在套题页的题图上手写**（交卷后每道题自动变成可写的画布，顶部有一条批注工具栏，默认红笔）；
     结构题在手写页里继续写（提交后自动进入批注模式）。讲完点底部常驻的「错题清零（整合进错题库）」→ 第三档点亮、主界面整套标绿。选择题交卷后每题下面也有「📝 加笔记区」，写过字的题进「复习 → 选择题批注」。
   - 每套题下面保留三个勾（做题 → 对答案 → 错题清零），纸上做的也能手动记录；在线提交后前两个自动打上。
   - 防误触：出现过 Apple Pencil 后，手掌 / 笔附近的手指触碰一律忽略，单指拖动才滚动；不再依赖浏览器的手势判断。
3. **复习**（2026-09-08 起只有三个页签）：
   - **选择题错题**：缩略图、复习模式（先想后翻、已掌握退出队列）、PDF 导出。
   - **选择题批注**：交卷后特意点过「📝 加笔记区」并写了字的选择题——视为学生自己标的复习重点。按套题分组，整张题图 + 批注 + 笔记区原样渲染（绿 = 已清零），点「继续批注」可补写。
   - **AS大题批注**：批注模式下手动加了笔记区并写了字的结构题，同上。
   - 结构题不判分、不进错题本；打字笔记和「题库」页签已删除（旧的打字笔记数据仍保留在库里，会显示在批注页里）。
4. **我的**：等级 / XP、统计、本周活动、18 个成就、本班 XP 榜、账号（改密码、退出）。
5. 所有记录存在账号里，换设备登录就有；没网时先记在本机，联网后自动补传（右上角显示同步状态）。旧版留在本机的记录第一次登录时自动并入。

测试账号：`test / test1234`（测试同学，标准计划，班级 Test）——老师自己试用；教师端班级筛选里它单独一班，不影响真实学生统计。

XP 规则：作答 1 题 +1，选择题答对再 +1，手写提交 1 题 +5，在线提交一套 +20，一套三个勾全打 +10，加笔记区写字 1 题 +2，掌握 1 道错题 +3。
等级 = √(XP/40)+1。成就在主页可见，都是按记录自动判定的。

## 老师怎么看

- **刷题进度**：每个学生的 P1/P2 完成率、落后几套、**在线做题**（提交套数、均分、作答题数、等级）、错题数、最近动静；
  点姓名展开每卷热力图 + 该生错题 + 薄弱考纲点。「全班进度矩阵」一屏看到所有学生每一套题做到第几步（红框 = 该生已过期未完成）。
- **批作业**（只针对 Paper 2 / 4 结构题；选择题自动判分不用批。2026-09-11 起**逐题**）：学生每「保存 · 看答案」一题，这一题就进待批，不用等整套提交。
  首页：待批题数 / 待批学生 / 今天新保存 / 已批，按学生、按套题两张表；「▶ 开始批改」按学生 → 套题 → 题号顺序把所有待批题连起来批，顶部进度条每格一题（绿 = 已批）。
  某一套的详情是「学生 × 题目」矩阵：绿 = 已批（显示分数）、橙 = 已保存待批、粉 = 写了还没保存（草稿，也能先批）。
  批改：Apple Pencil 直接在学生手写上打 ✓✗、写批语（15 色、三档笔宽，橡皮只擦老师的笔迹），打分（预填满分，「全对 ✓」一键），写评语；
  每一题自动保存，**批完一题学生就能看到这一题的红笔、分数和评语**（学生端每 45 秒、以及切回页面时拉一次，打开题目时再实时取一次）。
  以前已经写过、保存过的题都在服务器上，直接出现在待批里。
  「学生批注」开关可以看学生交卷后自己写的批注层（默认只看交卷时的原答案）。
- **讲题模式**（2026-09-08 新增，批作业 / 做题结果页的「🎤 讲题模式」）：全屏分两栏——左边是题目 + 老师板书（Apple Pencil 写，
  存在老师自己的账号里，下次讲还在），右边是这道题**全班每个人的手写答案**（1/2/3 列、筛「写了的 / 有失分」）。
  卡片可以 ⭐ 置顶、按住 ⠿ 拖动排序（顺序按套题记住），「← 讲」把某个学生的答案放到左边、在上面批注讲评，「⤢」放大看；中间分隔条可拖动改宽度。
- **做题结果**：选一张卷、一套题——
  选择题：每题的错误率、选项分布、**答错的同学（含所选选项）**，讲题时按题号对照；下面还有「学生 × 题目」矩阵和每人得分。
  结构题：「谁写了」矩阵（✓ 已提交 · ✎ 写了未提交 · 📝 有笔记），点格子看该生的手写原迹和笔记。
- **错题分析**：全班薄弱考纲点排行（人次、涉及学生、考纲要求原文）、多人错的同一道题、按学生列表；点题号看题目和答案解析。可按试卷 / 学生筛选。
- **学生管理**：添加学生、改姓名 / 班级 / 计划类型、重置密码、**清空记录**（保留账号）、删除；还能把旧错题本的「同步码」导入给某个学生。
- 页面每 15 秒自动刷新，右上角显示「实时同步中」。

数据库脚本按顺序：`_private/setup.sql`（建表）→ `update1.sql`（班级、Cui 老师）→ `update2.sql`（在线做题、手写、笔记、XP）→ **`update3.sql`（批作业 grades 表、讲题模式）**。都可重复运行。
没跑 update3.sql 之前，批作业页会提示先运行脚本，其他功能不受影响。
